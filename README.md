# Event Management Database

A PostgreSQL database for an event ticketing platform: organizers, venues, events and agendas, ticket tiers,
orders, payments, refunds, waitlists and door check-ins.

Goal: a schema that protects its own data. No double-booked rooms, no overselling, no refund larger than the
payment, and a ticket that only gets in once, even when many people act at the same moment.

Work in progress.
